Memory under scrutiny.

Tamhees checks what an AI remembers before that memory is allowed to guide an action. It tests the claim against provenance, freshness, current evidence, privacy, and permission—locally and deterministically.

Why memory needs a safety check

Remembering is useful. Blind trust is the problem.

A memory file can preserve what was said months ago. It cannot prove that the information is still current, correctly sourced, safe to retain, or permitted to control an action.

Where the idea came from

A useful memory file became too expensive to trust blindly.

A single GPTBrain.md-style project memory improved continuity while vibe coding. As it grew, the agent had to reread too much context on every prompt—and old, inferred, sensitive, or contradictory statements remained mixed together.

  1. One large fileHelpful continuity, but increasing latency and context use.
  2. Mixed-quality memoryFacts, guesses, secrets, and superseded decisions could look equally authoritative.
  3. Structured scrutinyTamhees adds claims, provenance, evidence, freshness, permission, auditing, and small task-specific context.

Four checks before action

Before memory controls an action, it must pass four checks.

1

Where did it come from?

Owner decision, repository evidence, test result, observation, or inference.

2

Is it still current?

Fresh memories may be usable. Old or superseded memories require review.

3

What does the project say now?

Current files and evidence may support or contradict the memory.

4

Is the AI permitted to act?

Confidence is not authority. Some actions still require the owner.

The engine returns one safe outcome: Trust, Recheck, Ask Owner, Block Action, or Forget/Redact.

Live local demonstration

See the safety check before an AI acts.

The live audit simulates the safety check that runs before an AI agent uses remembered project information. It compares the memory with current evidence, freshness, privacy, and permission, then decides whether the agent may trust it, recheck it, ask the owner, block the action, or forget/redact the information.

This is not a simulated chat response. Each example is evaluated by the real local audit and context engine; the interface cannot choose the outcome.

A local layer, not another coding agent

Works beside the coding agent you already use.

Tamhees does not replace Codex, Claude, Antigravity, or another agent. It prepares safer project context before work and evaluates proposed memory updates afterward.

Honest boundaries

What Version 1 does—and does not—claim.

Exact lexical retrieval

Normalized words and tags, not semantic understanding.

Deterministic token estimates

Repeatable local counts, not provider-exact tokenization.

Pattern-based detection

Defensive sensitive-value checks, not a universal secret guarantee.

Cooperative local adapters

They guide integrated agents but cannot force unrelated software to cooperate.
