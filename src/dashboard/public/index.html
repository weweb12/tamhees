HONEST BY DESIGN

A system that doubts memory should state its own limits.

Lexical, not semantic

Retrieval matches normalized words and tags. It does not understand intent like a human.

Estimated tokens

The local byte-based estimate can differ from a provider-specific tokenizer.

Defensive patterns

Secret-like detection reduces risk but cannot identify every possible credential.

Workflow cooperation

The engine cannot force an unrelated coding agent to obey unless that workflow invokes it.

Unsigned owner evidence

Owner evidence is not cryptographically signed in Version 1.

Unverified challenge detail

The detailed Doo judging criteria and submission fields remain unverified.

Doubtful Memory does not make AI memory perfect.

It makes memory accountable.
