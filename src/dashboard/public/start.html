        How it works

        Every memory carries its proof

        Where it came from, how sure it is, when it was last checked, and what it is allowed to change.

        Checked before every use

        The agent only receives what passes. Doubtful memories are labelled; wrong ones are held back.

        Notices, and forgets

        It reads the project itself to catch outdated memories, and "forget" erases the text for good.

        Runs locally. No AI model, no cloud, the same answer every time. 400+ automated tests.
