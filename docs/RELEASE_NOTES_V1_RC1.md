# Tamhees 1.0.0-rc.1 release notes

Tamhees is a local deterministic project-memory scrutiny engine. This release
candidate completes the safe local Phase 9 hardening work without publishing,
deploying, uploading, configuring a remote, or adding a runtime dependency.

## Highlights

- Canonical claims, evidence, audits, lifecycle journals, deterministic
  retrieval, hard context budgets, and privacy-first mutation rules.
- Five cooperative local adapters and exactly four strict stdio MCP tools.
- Loopback-only judge dashboard with seven real fixed-fixture audit paths.
- Explicit fail-closed migration from a lone valid `.gptbrain/` store to
  `.tamhees/`.
- Deterministic 22-scenario benchmark and integrity-checked dashboard evidence.
- Release threat model, judge guide, FAQ, walkthrough script, checklist,
  dependency notices, and dry-run-first local distribution preparation.

## Compatibility

- Node.js `>=22` is declared.
- Development verification on this machine uses Node 24.
- Node 22 execution remains an owner gate because that runtime is not installed
  locally and this task does not download runtimes.
- Windows PowerShell is used by the optional local archive workflow.

## Limitations and release gate

The candidate is `UNLICENSED`, unpublished, and not externally security
audited. Exact lexical retrieval, estimated tokens, pattern-based secret
detection, cooperative adapters, and fixed benchmark fixtures remain deliberate
limitations. Independent Phase 9 local verification is complete. Final release
still requires Node 22 execution, real assistive-technology/device and
second-laptop portable review, license and publication decisions, and separate
authorization for challenge-submission preparation.
