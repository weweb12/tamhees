# Doubtful Memory — Antigravity Workspace Rule

Read `AGENTS.md` at the repository root before every task.

## Required behavior

- Preserve existing user changes. Inspect `git status` and diffs before editing.
- Never install packages, add services, create costs, or configure remotes without owner approval.
- Local-only: no telemetry, no hosted models, no cloud databases, no external APIs.
- Distinguish verified evidence from inference.
- Run required tests and verification before reporting success.
- End material tasks with a structured completion report.
